    Input rules and honest limits
    Relative line-based paths only. No parent/dot segments, absolute drives, colons, empty segments, edge whitespace, controls, invisible format characters or unpaired surrogates. Maximum depth 24; each segment up to 120 UTF-16 units. Git-quoted, NUL-delimited, indented outline and tree-command formats are not supported. Names are not normalized for matching; NFC + lowercase is only a warning. This is not a cross-platform filename validator.
    Any input error blocks all comparison/tree exports. Duplicates are merged with warnings. Preview shows the first 500 tree lines; downloads contain the full tree. Receipts show 50 changes per page and up to 100 diagnostic messages, with omissions disclosed. Textareas may normalize line endings. Native browser visual checks and a real screenshot are pending; simulated DOM checks do not verify rendering or downloaded file destinations.
